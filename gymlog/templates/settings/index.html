Data & PWA

Your permanent training data is stored in Neon PostgreSQL. The installable app shell and static assets are cached by the service worker.

  • Offline workout edits are stored in IndexedDB and marked pending sync.
  • Sync uses a unique workout ID so retries never create duplicate sessions.
  • If the server copy changed after your offline copy was saved, a conflict is shown instead of overwriting newer data.
